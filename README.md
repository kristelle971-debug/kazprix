# KazPrix 🌿

**Surveiller et comparer les prix en Guadeloupe**

KazPrix est une Progressive Web App (PWA) gratuite qui permet de :
- 🛒 Créer et gérer un panier de courses
- 💰 Enregistrer les prix par magasin avec l'historique
- 📷 Scanner les codes-barres (pré-remplissage via OpenFoodFacts)
- 🏪 Comparer les prix entre magasins
- 📊 Suivre l'évolution des prix dans le temps

## Stack technique
- **Frontend** : HTML / CSS / JS vanilla (PWA installable)
- **Base de données** : Supabase (PostgreSQL)
- **Hébergement** : GitHub Pages
- **Scan** : Html5-QRCode + OpenFoodFacts API

## Installation
L'app est accessible directement depuis le navigateur et peut être installée sur l'écran d'accueil comme une app native.
